Политика обработки персональных данных

Настоящая политика определяет порядок обработки персональных данных пользователей сайта Дарьи Шухриной.

1. Какие данные собираются

При заполнении формы заявки на сайте могут собираться: имя, номер телефона, интересующая ситуация, комментарий.

2. Цель обработки

Данные используются исключительно для связи с пользователем по его заявке и не передаются третьим лицам, за исключением сервисов, обеспечивающих техническую передачу заявки (Telegram).

3. Согласие

Отправляя форму на сайте, пользователь подтверждает согласие на обработку указанных персональных данных в целях, указанных выше.

4. Хранение и защита

Данные хранятся и передаются с использованием защищённых каналов связи. Срок хранения ограничен временем, необходимым для обработки заявки.

5. Контакты

По вопросам обработки персональных данных обращайтесь через Telegram: @darya_shukhrina.
